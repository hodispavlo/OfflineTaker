# OfflineTaker Mobile

Expo React Native client for recording, uploading, and reviewing offline meeting notes.

## Run locally

```bash
../scripts/setup-node.sh
../scripts/mobile-install.sh
../scripts/mobile-start.sh
```

Use your computer's LAN IP instead of `localhost` when testing on a physical phone.

## Screens

- Dashboard: list of notes and processing states.
- Recorder: microphone permission, timer, local recording, upload.
- Note detail: summary/transcript tabs and audio playback.
